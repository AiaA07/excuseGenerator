SITE: Excuse Generator 3000 — Modern Edition
==============================================================

ROLE / CONTEXT
--------------
Role: You are a product designer building a web-based utility tool.
Context: You are creating the **Excuse Generator 3000** — a clean, functional web tool that helps users generate believable (and hilariously unbelievable) excuses for everyday modern situations. The tool includes a "Lie Detector" meter that rates each excuse's plausibility from "Truthful" to "Total Lie." No mascots, no character art, no unnecessary illustrations. Just a sharp, friendly UI with a lie detector as the centerpiece.

No knights, no dogs, no King Arthur, no Pixar characters, no medieval themes. Pure excuse utility with comedic copy.

No specific image generation tools required (Nano Banana, etc.). Use placeholder SVGs or simple geometric icons where needed.

BUILD STACK
-----------
1. Stitch (layout generation)
2. UI UX Pro Max (style / palette / typography selection)
3. Firecrawl (reference scrape)
4. Magic / 21st.dev (marketing blocks)
5. Brand skill (voice + messaging)
6. Design skill (logo, icons, OG image)
7. Design System skill (token architecture)
8. UI Styling skill (shadcn/ui interactive components)

PURPOSE
-------
A comedic excuse generator tool that helps users craft modern excuses for real-life scenarios (work, dating, sports, general chaos), then rates their believability on an animated "Lie Detector" meter. Visitors can browse excuses by category, generate random ones, submit custom excuses, and share the funniest results.

==============================================================
STEP 2 — BRAND VOICE (for `brand` skill)
==============================================================

Voice archetype: The Witty Best Friend — warm, clever, gently sarcastic. Speaks like a smart friend who will help you lie but also lovingly call you out.

Tone dimensions (scale 1–5):
- Formal ↔ Casual:        1 (very casual)
- Serious ↔ Playful:      5 (extremely playful)
- Reserved ↔ Expressive:  4 (expressive but not exhausting)
- Modern ↔ Timeless:      1 (modern — references texting, WiFi, meetings)

Voice rules:
- Use everyday, conversational language.
- No character puns (no dog/cat/animal references).
- Second-person (“you,” “your”) — direct and funny.
- Short, punchy sentences. The Lie Detector verdict should feel like a playful roast from a friend.
- Light tech slang: “my WiFi ghosted me,” “calendar betrayal,” “sync error,” “algorithm said no.”

Words to use: oops, yikes, no way, plausible, hmm, sus, totally believable, big lie energy, farewell, excommunicado (for epic lies only)
Words to avoid: leverage, synergy, solutions, premium, optimal, deliverables

Messaging framework:
- Tagline (≤7 words):        “Your excuse. Rated. Exposed.”
- Value prop (≤20 words):    “Generate modern excuses. Our Lie Detector rates your alibi’s believability — from Truthful to Total Lie.”
- Key phrases (3–5):         “My WiFi ate my Zoom link,” “Sorry, my calendar did a sync error,” “Plausible — you might survive,” “That’s a stretch, my friend.”

==============================================================
STEP 3 — DESIGN SYSTEM (for `ui-ux-pro-max` + `design-system`)
==============================================================

Style keywords: clean, functional, warm, playful, modern, friendly, rounded, utility-focused

Preferred style direction: soft claymorphism with clean lines — generous corner radii, tactile shadows, no sharp brutalism. The Lie Detector meter looks like a playful dashboard gauge, not a cartoon.

COLOR SYSTEM (semantic roles):
- Primary:         warm coral / peachy red (the "LIE" zone on meter, primary buttons)
- Secondary:       deep slate blue (secondary buttons, interactive elements)
- Tertiary:        soft moss green (the "TRUTH" zone on meter)
- Accent:          warm golden yellow (meter needle, hover states, glows)
- Surface-base:    cream / off-white (#FFF8EF)
- Surface-raised:  soft warm beige (#F5EDE4)
- Ink:             rich warm brown / dark slate (#2C241E)
- Success/info:    sage green / soft sky blue

Contrast: WCAG AA minimum, AAA for body copy.

TYPOGRAPHY:
- Display:   a friendly rounded sans-serif or modern slab (e.g., DM Serif Display, or Satoshi)
- Body:      humanist sans-serif, high x-height, 16–18px base (Inter, Noto Sans)
- Accent:    a single italic or monospace for Lie Detector verdicts only
- Type scale: 1.250 (major third)
- Line height: 1.55 body, 1.15 display

SPACING & LAYOUT:
- Spacing scale (4px base): 4, 8, 12, 16, 24, 32, 48, 64, 96, 128
- Container max-width: 1280px
- Grid: 12-col desktop, 8-col tablet, 4-col mobile
- Section vertical rhythm: 96px desktop / 64px tablet / 48px mobile

RADII:
- sm 8px | md 16px | lg 24px | xl 32px | pill 9999px
Default card radius: lg. Buttons: pill. Lie Detector meter housing: xl.

ELEVATION (soft shadow, no sharp drops):
- sm  0 2px 8px   rgba(0,0,0,0.05)
- md  0 8px 24px  rgba(0,0,0,0.08)
- lg  0 16px 48px rgba(0,0,0,0.10)

MOTION LANGUAGE:
- Easing:     cubic-bezier(0.22, 1, 0.36, 1)
- Durations:  micro 150ms, standard 300ms, expressive 600ms, hero 900ms
- Stagger:    80ms between siblings on scroll-reveal
- Hover:      button lift 2px + shadow md→lg, 200ms
- Hero:       title fade+rise 24px over 900ms
- Lie Detector: needle swing 600ms with overshoot ease, LED blink 150ms
- prefers-reduced-motion: all transforms/opacity collapse to opacity only at 200ms

==============================================================
STEP 5 — SECTIONS & LAYOUT (for Stitch)
==============================================================
Section order:

1. Hero            — brand name "Excuse Generator 3000," tagline, large "GENERATE EXCUSE" CTA, secondary button (optional), no character illustrations.
2. Lie Detector    — animated meter display, shows current excuse's rating (Truthful / Plausible / Stretching / That's a Lie), needle animation on generation, rating label with verdict.
3. Category Selector — pill-shaped filters: Work, Sports & Fitness, Dating, General Chaos, Custom Excuse.
4. Excuse Output   — large clean card displaying generated excuse text, copy button, share button, regenerate button.
5. Custom Excuse Builder — form fields (situation, your "reason"), submits to detector for rating.
6. Top Rated Excuses — simple leaderboard of community's funniest/most believable excuses (text-only or minimal cards).
7. Testimonials    — carousel of funny user reviews ("This lie got me out of a meeting!") — text-only.
8. FAQ             — accordion (Is this legally binding? Can I use these for real? How does the lie detector work? etc.)
9. Footer          — fine print ("For entertainment purposes only. We are not responsible for misused excuses.")

No character cards, no mascots, no unnecessary image sections.

==============================================================
STEP 6 — IMAGERY
==============================================================
Global rule: No character illustrations, no dogs, no knights, no Pixar-style renders. Use minimal geometric SVGs, simple icons, or no images at all where possible. The UI should be driven by typography, color, and the Lie Detector meter.

Allowed:
- Simple line icons (Feather, Lucide, or Heroicons style) for categories and actions.
- Abstract SVG shapes for visual interest (blobs, rounded geometric forms) — strictly abstract, no faces or characters.
- No hero illustrations of people or animals.

If imagery is absolutely required for layout balance, use subtle abstract gradient blobs or pattern overlays — never representational characters.

Aspect ratios for any optional abstract graphics: flexible.
